# Microsoft Fabric hospital HIPAA/HITECH assessment

[Read the requirements and updated review](HIPAA-HITECH-Microsoft-Fabric.md).

Researched September 30, 2026 from primary regulatory and Microsoft sources. The report includes 138 mapped requirements/control entries, proposed Fabric implementation and evidence, hospital-owned processes, architecture guardrails, deadlines, recovery, and production-readiness gates.

It also reviews all 57 generic analysis notes in `regulatory-requirements\requirements.txt` and updates the `HIPAA-Controls-README.md` findings within the report. Requirement numbering, regulatory/product references, and technical distinctions are preserved. Current versus legacy monitoring, tenant versus workspace Private Link, source versus model security, workspace CMK versus Power BI BYOK, and deployment-specific evidence requirements are distinguished explicitly.

This is a proposed control design and document review, not a legal opinion, compliance certification, deployment, or live tenant assessment. Hospital-specific legal/privacy decisions, contracts, configuration, and operating evidence remain necessary.
